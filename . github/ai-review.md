Роль: Ты — Senior Rust Developer и DevOps-инженер. Твоя задача — доработать существующее приложение для управления сетевыми подключениями (обход DPI) до полностью рабочего состояния.

Контекст:
У меня есть репозиторий с проектом. В нем уже есть структура папок (src, src-tauri, ui, tmp) и файлы (Cargo.toml, build.rs, README.md). Приложение задумано как GUI/CLI инструмент для включения и выключения обхода блокировок (на основе логики zapret).

Задача:
1. Проанализируй текущую структуру проекта и существующий код.
2. Допиши все недостающие файлы и модули, чтобы приложение стало рабочим (сборка без ошибок, запуск интерфейса, выполнение команд).
3. Реализуй функции:
   - Запуск/остановка процесса обхода (вызов внешнего исполняемого файла или встроенной логики).
   - Проверка статуса (работает ли обход).
   - Корректная обработка путей к бинарникам (winws.exe / nfqws) в зависимости от ОС.
4. Проведи самостоятельную проверку (Self-test): напиши unit-тесты для критических частей и проверь, что `cargo build` проходит без ошибок.
5. полное работающее приложении на rust и tauriV2

Ограничения:
- Не ломай существующую архитектуру (Tauri/Rust), если она уже есть.
- Код должен быть безопасным и обрабатывать ошибки (Result/Option), не паниковать при отсутствии файлов.
- Если нужны внешние зависимости, добавь их в Cargo.toml.

Формат ответа:
- Сначала краткий план действий (что будешь делать).

- В конце — команды для сборки и проверки.
